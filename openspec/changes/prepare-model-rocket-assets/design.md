# Design

Use an isolated wrapper over SpaceFoxCountdownStatus. Current76px baseline remains
source-bound and unchanged. Compare108px at[30,126,46,108],124px at[22,118,54,124]
and an intentionally aggressive140px candidate. Initial selection124px is a
hypothesis, not acceptance. All shapes use a64×160 source viewport.

Keep a single registry.source.json as authoring input. Standalone SVGs are editable
sources. build_rocket_pack.py validates entries and uses the already installed
rsvg-convert to generate transparent PNG candidates and a digest manifest. No
prerequisite is installed. Browser SVG and PNG structure checks do not qualify
Garmin memory, native font/image support, AOD or actual human recognition.

Five model-specific shape references come from SpaceX, RocketLab and ESA/CNES/
Arianespace. Draw new schematics; do not copy reference imagery. Four Ariane64
boosters are separated schematically to distinguish the configuration; this is
not an engineering projection or an exact per-mission coating.

Use original vector letter badges SX/RL/AS instead of distributing official logos
with unestablished default-pack rights. Names identify operators; the MIT license
covers original artwork/code, not third-party trademarks. Preserve readable
operator/model text in the header, because tiny body marks are supplementary.

The owner selected origin of rocket/operator. Default mode uses a curated model
origin (Falcon US, Electron NZ, Ariane European programme); an operator mode uses
separate company-country metadata (SpaceX US, RocketLab US, Arianespace FR).
Electron's NZ family-origin mark is a simplified design/manufacturing association,
not a claim of exclusively NZ components; RocketLab has a US corporate HQ and NZ
production. The European flag represents a multinational programme, not a country.
Unknown selected origin is omitted. No origin is derived from launch location.
Additional Heavy/A64 assets appear in the
asset sheet; they do not fabricate a scheduled launch or pad association.

Measure56 fresh states (three sizes ×14 scenes in rocket-origin mode plus14 at124px
in operator-origin mode) on the selected black/fade
composition. Retain the existing76px hero control after exact source/fixture
verification. Test model/identity/asset rejection directly, then inspect actual
native-size pictures. Country/mark recognition is a visual self-review limitation,
not a validated glance test. Existing unrelated green suites are retained.
