# Quiet-field SDK observation

Disposable network-none Linux SDK 9.3 FR165/API5.2 simulator, isolated storage and test identity; no physical watch or private profile values. The small [probe](Probe.mc.txt) prints only availability/type/null categories, not field values. It compiled successfully and [ran](run.log) once in foreground and once in an immediately registered background event. In both contexts the simulator exposed Boolean `doNotDisturb` and `vibrateOn`; `ActivityMonitor.Info` and `isSleepMode` existed with a non-null Boolean; profile sleep and wake existed as non-null `Time.Duration` values. This is the simulator's default state and does not establish any actual watch firmware, user setting, real sleep or DND behavior. No state was toggled and no physical vibration was measured. Launcher exit was a deliberate 35-second timeout after both markers; this is not a clean application exit.
