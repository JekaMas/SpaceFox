# Production-bound state-machine properties

The 15 selector families below are campaign workloads, not 15 claims of independent product state machines. Each is a different owner or adapter/property boundary; every listed workload is required to exercise its production code for at least 600 productive seconds. Host budget, publication and deployment retain their 600-second results; source is reopened for SOURCE_COARSE/nominal NET and a source-only rerun. See `HOST-CAMPAIGN.md`. Current observations are short SDK tests; none establishes native 600-second completion, hardware, raster pixels, phone service, or a live network. Raw SDK launcher exit 1 accompanies the complete selected PASS tables and is not described as exit 0.

Automatic native trace minimization is not implemented; retained focused red traces and directed regressions are the available minimization boundary.
