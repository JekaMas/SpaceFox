# GitHub publication: SpaceFox 0.1.20

On 16 November 2026 the independently reviewed source was fast-forwarded to GitHub main and published as the regular, non-draft [v0.1.20 release](https://github.com/JekaMas/SpaceFox/releases/tag/v0.1.20). Immediately after publication, both remote main and the tag resolved to `4d97967b1b839683881f5b61c4e4e3ac9c126f26`. The packages were built from `30dc0421d35e77b76e1451d6dfd4b1a5b9d9a144`; the 316 compiled inputs were independently confirmed unchanged at the reviewed source.

The public release contains the signed IQ export for 42 profiles, FR165 and FR165 Music PRGs, public signing key, compact build summary, checksums, license and installation, handoff, verification, release notes and third-party notices. The full private build receipt and raw device logs were not published.

GitHub reported all 12 intended assets uploaded. A separate download of each of the three binary assets produced the following SHA-256 values, matching the accepted build receipts and GitHub asset digests:
