## Investigation and design

The production 0.1.18 debug map associates the reported timeout stack with foreground reload and `NativeWireHash`, subject to the installed-binary identity boundary. That hash frame belongs to a synchronous callback which also parses and validates the feed and catalog, computes multiple source-bound hashes and persists a commit. The baseline 191 ms simulator parser-owner measurement includes owner callbacks and hashes; it is not a measurement of pure JSON cost or a physical watchdog margin.

`NativeIncomingReadJob`, `NativePreparedBridgeFeed`, `NativeFeedPromotion` and `NativeRestoreJob` retain the existing source, publisher, marker, readback and inverse-witness checks while moving work into resumable foreground steps. The parser has an explicit stack and lexical budget; hash steps process bounded slices. The selected launch is initially syntax checked, then reconstructed from its recorded original span after successor parsing; each successor is validated before conversion to its compact scene, with count, duplicate and terminal checks still required before publication. The selected launch is fully validated before catalog loading except for its catalog membership, which is checked after the catalog has been authenticated and parsed. Validation-only fields can then be released; raw and semantic identities still use the exact original input. Independent oracle tests compare retained facts, raw spans and hashes with the original parser.

The scheduler groups at most four steps and checks elapsed time between them. Parser-release boundaries explicitly yield. Jobs survive LOW and reject changed markers; unexpected callback failure releases owner cycles and defers a strict restore to a later event. Reconstructible renderer, scene build, fitness subscriptions and locale resources are suspended while preparation owns heap, and restored afterward. Bundled map metadata is constructed lazily in the same 54-entry order, avoiding the eager live set. The previous accepted clock, countdown and scene remain available during preparation.

Background network work retains finite input and object caps; it uses the supported callback/event flow rather than assuming a Timer in Background. Verified object prefixes are reused only within the event and a fresh closure scan is required before completion. Reminder comparison remains a bounded synchronous background callback and is measured separately. `evidence/CALLERS.md` records each caller and the limits of the observed timing and memory results.

Garmin's [Timer API](https://developer.garmin.com/connect-iq/api-docs/Toybox/Timer.html) lists WatchFace, not Background; [Backgrounding](https://developer.garmin.com/connect-iq/articles/core-topics/Backgrounding.html) documents termination and its 30-second limit. The tests use the captured real payload and FR165M SDK simulator. None establishes a universal deadline or physical-watch margin. Physical FR165 Music cold start, reopen and at least 15 minutes ordinary use on the exact candidate remain separate acceptance gates.

## 0.1.20 physical follow-up

The owner reported missing data, point and the expected LOW composition after the signed 0.1.20 transfer. This remains a physical failure witness; current encrypted application storage prevents externally identifying its precise stage. The current public feed, pinned catalog and full selected closure were captured and verified. A fresh SDK background service fetched the feed and catalog and foreground admitted the selected site before optional art, while a second service event resumed the remaining objects without re-fetching the feed. Those finite observations do not diagnose the watch/phone-specific failure. The user chose a display-only estimate for a validated inexact announced NET: use `~T−` or `~T+` without changing feed identity, exactness, scheduling, reminder or liftoff semantics. A backwards-compatible optional field retains this reference in existing sealed upcoming rows.

LOW uses the same `SceneAod` composition during an in-progress admission; its temporary map, font and rest-mask resources are acquired for the draw and released at callback return. The ordinary no-context LOW renderer has a default geographic outline and does not fabricate a point. Resource lifetime across interrupted parser and SFR work requires the retained stock/lifecycle evidence, not the unit-test heap sample alone. Bounded stage, scheduling and filtered durable-metadata trace messages expose a later diagnostic watch run without printing stored feed, health, URL, tokens or hashes.
