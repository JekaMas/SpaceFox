# Independent literal sharing decisions

The user permits shared drawings only for an externally VERY similar vehicle or no usable exact reference. The table applies that condition per group; a generic/unspecified identifier cannot establish an exact booster/fairing choice merely because a family is photographed. Representative exceptions do not assert all family members identical, and are not a permanent exemption if a later source identifies the actual configuration. Distinct named visible choices (H3/Vulcan booster counts/fairing lengths, Soyuz short/long, Ariane62/64) remain distinct. No arbitrary cosmetic uniqueness was introduced.
