# B1 and published 0.1.20 source integration

The integrated source retains 0.1.20's incremental parse/hash, strict atomic promotion and recovery, while restoring B1's first-frame clock/date, optional-resource containment, wake progress and bounded provider icons. LOW/OFF pauses admission without throwing away progress; hide cancels and disposes it. Fallback includes the current qualified launch facts without increasing their source precision. This is source-stage qualification; no 0.1.21 release package or physical test is claimed.

The new current source test table (`integration021-tests.log`) ran 21 named SDK cases on the pre-timer-fix source, including captured HTTP-boundary cold acquisition and strict cache reopen, incomplete/invalid inputs, atomic visibility, supersession, failed promotion and restoration of source age, ACTIVE/LOW decoder progress, clock fallback and provider icon limits. The captured feed test substitutes HTTP and its test-host heap is not the stock heap. The named table has SDK raw exit 1 but is complete and error-free under the existing strict parser. Its initial setup/assertion failures and the first incomplete table are retained alongside it.

The fix marks admission pending before scheduling restore so the first fallback frame cannot start fitness timers simultaneously. Six directly affected SDK cases passed in `integration021-startup-fix-tests.log`; unrelated 21-case observations above retain their original source boundary. No claim is made that they were run against the later binary.
