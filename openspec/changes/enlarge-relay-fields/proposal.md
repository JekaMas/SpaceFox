# Proposal

## Why

The owner selected rocket + company above the mission purpose. The four fitness
values need more room, and the countdown should be read together with current
time. Map treatments must retain a visible, correctly located launch point.

## What Changes

- Fix the accepted header and compare three bounded browser compositions.
- Enlarge all four independently configurable values; offer a separate small
  watch-battery indicator without consuming a slot.
- Move countdown below current time, compare map cutout/fade/globe and dark backgrounds.
- Preserve readable launch place, rocket identity and distinct conditional status signs.

## Capabilities

### New Capabilities

- `focus-layout`: Browser layout comparison and bounded evidence for the accepted mission grouping.

### Modified Capabilities

None. Existing native requirements remain in the unimplemented watchface change.

## Impact

New sibling `prototype/focus/` only; frozen feature/marker/composition/relay
renderers remain untouched. Update native design and current preview links.
No native SDK, service, live health data or power claim. Original work is MIT.
