# Design

This is a bounded follow-up to M2-31 and the accepted company header. Three map
treatments share one enlarged layout, allowing the map format to be compared
without also changing fitness typography. Keep all prior owners unchanged.

Use four 32px values in a 2×2 grid, with icons and coherent column axes. Preserve
the source field roles. A separate device-battery fixture is nullable; do not infer
it from Body Battery. Current time and countdown share a centered axis. Country/site
moves below the fields; actual circular geometry decides feasibility.

Use the existing local Noto Sans and condensed numerals. Default black background;
offer dark navy for comparison, not a screen-power assertion. Fade geographic paint
only, not marker or labels. All points must come from the existing scene catalog.

Before implementation: plan source-bound browser measurement for 3×14 scenes,
retaining all failures; no new human/native/independent claims. Reuse the current
DOM/ink-box/SVG metric (v3), adding dedicated-battery geometry and projected-anchor
checks. Targets: zero semantic/geometry failures, values ≥28px, unchanged clock ink,
countdown before fields, marker clearance ≥4px and true source identity. These are
browser heuristics, not psychophysical legibility thresholds or AMOLED photometry.

Qualify the evidence auditor with missing-field/collision and missing/displaced-point
counterexamples. Record exact source hashes once the batch is stable. Existing
green suites are retained because their owners/fixtures/assertions are unchanged.

Measured increment: both backgrounds expand the planned42 configurations to84;
12 fourth-slot reassignments bring the final set to96. V1 used28px values and
hard inherited backing; visual review prompted32px and feathered map-only masks.
The unchanged v3 raster metric is conservatively interpreted for black background.
The full four-slot UI reassignment is separately captured; hidden fields/native
settings persistence and36-language qualification are not implemented here.
