# Composition features and mutation hypotheses

All are hypotheses, not established ergonomic effects. Fonts, data and ring24
stay fixed; projection/camera moves the true site, never an arbitrary decorative dot.

| Feature | G1 hypotheses | G2 discriminator | G3 refinement |
|---|---|---|---|
| Geography footprint | Small separate globe; right hemisphere; wide atlas; upper globe; broad horizon; horizontal belt | Separate text/map lanes versus continuous shaded background | Exact size/placement around observed clearances |
| Map lightness | Blue, teal, neutral silver | Increase sea value on ocean-heavy views while retaining land separation | Tune sea/land balance without losing small text |
| Figure-ground | Bright land/darker sea; no opaque mission rectangles | Move text outside geography versus one smooth shading plane | Avoid new local black cutouts |
| Projection | Orthographic globe or equirectangular strip | Preserve globe curvature versus explicit cropped map window | Camera/roll where actual points stay readable |
| Grid | Opacity0.30/0.20/0.12 by treatment | Reduce competing line detail, retain curvature | Strong/quiet paired alternative |
| Coastline | Fine0.8px outline | Is it still legible when the grid is quiet? | Adjust outline rather than dimming the entire planet |
| Text axis | Whole centre, time/globe pair, mission grouping | Repair inherited 25px mission-axis offset; compare centre/left mission | Verify actual optical grouping in images |
| Metadata grouping | Three full labels in a natural vertical flow | Wider288px block versus side/row grouping; long strings expose crowding | Keep role order without unnecessary extra rows |
| Foreground/background | Transparent labels, whole geographic form | Actual sampled background contrast and usable area | Preserve a bright unreserved region |
| Status/fields | Separate header status; four unchanged field slots | Fix genuine collisions without shrinking glyphs | Observe short/long field values |
| Rocket | Existing model-specific SVG, unchanged catalog | Move/scale artwork within geometric constraints | Balance with narrative group, not a detached spare icon |
| Whitespace | Existing lower site/countdown group | Remove unused gaps while preserving hierarchy | Equal-data review of whole circular silhouette |

No weighted aesthetic score. Gate failures are retained. Area, luminance,
connectivity and declared-axis residuals are descriptors/engineering constraints;
they do not determine beauty, reading speed or user preference. Feature Congestion
was researched, but its published multi-scale perceptual algorithm is not
implemented here; simple pixel area is not relabeled as that algorithm.
