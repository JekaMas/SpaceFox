# Own visual composition review

Scope: current authoring agent; not an independent reviewer, human preference
study, response-time experiment or Garmin device test. Browser JPEGs at1280×720
are separate from SVG-only map diagnostics.

## Observed comparisons

- G1: all18 overview proposals across three pages. Bright land is visible; large
  background maps compete with metadata. Small globe and horizontal belt provide
  clearer separation. No candidate passes all author scenes.
- G2: page1 and page2 snapshots. Wide metadata repairs long labels, but forcing a
  row fails long company/purpose cases. Smooth shading dims geography without
  preserving all text contrast. Two layouts pass8/8.
- G3: all six in overview and two native390 pages. Larger/rolled globe C3-12 is
  rejected for title contrast; mirrored C3-22 for long operator/rocket proximity.
- Final: short/long RU overview, three native long-RU and three native long-EN
  pairs, real catalog Mahia/Kourou views. Both marker and original R4 comparisons
  are available. The ten controls remain exact, not redrawn approximations.
- Final globe C3-11: strongest coherent space theme. Bright continuous limb is
  distinct from the old sliced planet. Time moves left/down as a deliberate pair
  with geography; lower data remains centred. This is own visual preference.
- Side window C3-21: clean separation and bright geography, but long text forms
  a denser column. Mahia shows much ocean and less context; do not present this as
  equally good for every location or a proven ergonomic winner.
- Belt C3-32: clear functional sequence, preserved map window, short rocket/company
  form one row and long values wrap. The lower whitespace is a pause, not a
  measured defect to fill with more information. Stack C3-31 is a passing alternate.

## Conclusion

Recommend C3-11 first, C3-32 as a different strong direction, C3-21 as a spatial
alternative with an explicit context tradeoff. No unresolved observed overlap is
accepted in these finite scenes. Numerical PASS does not establish reading speed,
country recognition, child preference or universal visual superiority.

Actual snapshots are stored alongside this file. Fixed layout parameters and
rendering source preceded the six additional scenes; only the erroneous opacity
accounting of old controls was subsequently corrected and transparently retained.
