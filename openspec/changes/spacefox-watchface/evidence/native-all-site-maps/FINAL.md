This generic proof closure contains the committed 2026–2036 source cohort and local FR165 simulator observations. It is author self-verified; independent peer and root judgment remain pending. The default test run reads this directory without a private checkout. `SPACEFOX_NATIVE_ALL_SITE_EVIDENCE` is an optional explicit override.

The author branch was integrated with the 0.1.12 product source `02a95aafceb6908494869c50b01d492349dd0d9d` before handoff. Captures retain their original 0.1.11-era probe bindings; the relevant decoder, renderer, point/context and map-producer owners remained unchanged in that integration. Release/menu/version changes do not turn those observations into a fresh 0.1.12 native execution.

The current catalog has 224 required site IDs: 189 fixed finite reference positions, 28 finite mobile reference positions, six fixed unknown positions and one mobile unknown. Mobile reference coordinates are not event positions. Five inactive-but-future-referenced pads and three sourced supplements remain included. Coordinates are source references, not independent pad surveys or proof of worldwide completeness.

[`site-to-native-frame.csv`](site-to-native-frame.csv) and [`index.html`](index.html) link each ID to its source facts, native frame and log. `contact-01.png` through `contact-12.png` follow CSV order. The small barcode is diagnostic-only. Actual production raster decoding and scene rendering are observed for each fixed site, while 35 no-point scenes are checked for false pins. This probe substitutes a resource-backed store and injected scene context and therefore does not establish complete feed/cache admission for every site. Its watch-app heap was 781,880 bytes; a separate single-site ordinary-watchface discriminator reported 126,784 bytes. Neither establishes ordinary or background memory bounds for the cohort. A retained historical native unit test supports the zero-coordinate distinction under explicitly checked current-source applicability; its 8 MiB test-mode budget is distinct from ordinary execution, and the receipt does not measure its actual heap. It is not a fresh current-binary unit run.
