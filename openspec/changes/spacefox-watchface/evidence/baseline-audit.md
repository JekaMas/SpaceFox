# Сверка исходного запроса и макета

Дата: 2026-11-10. Историческая область: `prototype/mission.html` в начальном
коммите `6ee3074` и исходная спецификация этого изменения. Последующее изменение
компоновки описано в [layout-review-v4.md](layout-review-v4.md). Это авторская
сверка, не независимое ревью и не нативный тест; прежний SHA относится к прежним
байтам и не обновляется для сокрытия изменения макета.

Последняя правка пользователя заменяет постоянное время обновления компактными
индикаторами. Поэтому фраза «на экране будет время последнего успешного
обновления» из более раннего ответа **не возвращается** в главный экран.
Успешное обновление хранится внутри состояния для определения давности данных.

| Требование | Что уже есть в макете | Чего ещё нет | Контракт |
| --- | --- | --- | --- |
| Текущее время и четыре настраиваемых поля | Крупное время, выбор/скрытие полей | Время Garmin и реальные метрики; макет привязан к Dubai | `watchface` |
| Автообновление примерно раз в пять минут через телефон | Нет; только условный отсчёт | Фоновый сервис, телефонный мост, provider/cache | `launch-schedule` |
| Следующий запуск и пересчёт при переносе | Три выбираемых примера, демонстрационный +20 минут | Автовыбор из реального расписания и сравнение стабильных launch IDs | `launch-schedule` |
| Ракета соответствует модели; общий fallback | Три CSS-миниатюры: Falcon 9, Electron, Ariane 62 | Настоящий каталог изображений, загрузка и generic fallback | `watchface`, `visual-catalog` |
| Точка космодрома и поворот глобуса; плоская карта | Данные Natural Earth, три точки, две проекции | Обновляемые site IDs/координаты и нативная отрисовка | `watchface`, `visual-catalog` |
| Компактные признаки переноса и давности | Янтарный `!`, cloud-off, пунктир, неизвестное время | Нативное вычисление состояний по принятому расписанию | `watchface`, `launch-schedule` |
| Простая анимация запуска | Короткое движение/зажигание и поворот Земли по кнопке | Нативный wrist/sleep lifecycle и проверка мощности/памяти | `watchface` |
| Легко добавлять и обновлять точки/изображения | Нет; исходные примеры зашиты в HTML/CSS | Версионируемый каталог, инструменты, совместимые ассеты и атомарные обновления | `visual-catalog` |

## Сохранённые наблюдения

Исходный SHA-256:
`ac485fd3635e0626a5e4287f3e4fbb116e719308edb4dd53e83faa1da57af9ee`.
Совпадение байтов при копировании в репозиторий проверено. Ранее в этом же
обсуждении в браузере наблюдались обычное состояние, перенос с известным и
неизвестным временем, совместные перенос/устаревание, смена ракеты/проекции,
длинное числовое поле, скрытие поля и короткая анимация. Значки сдвинуты внутрь
безопасной области круга после обнаружения обрезания на узком предпросмотре.

Эти наблюдения относятся к исходному макету. Копирование и создание оболочки
не считаются новым тестированием Garmin, живого API или каталога.

В предыдущей проверке среды `monkeyc` и `connectiq` не были найдены в PATH,
стандартная директория SDK отсутствовала. Запросы JSON к development API из
Python вернули HTTP 403; публичные HTML-страницы API были доступны через поиск.
Эти исторические наблюдения не выданы за новую проверку текущего доступа.

## Проверка смысла спецификаций

Включены случаи, в которых внешне похожая реализация дала бы ложный результат:
истёкший таймер без подтверждения старта; перенос без нового времени; свежий
кеш при кратком отключении телефона; одновременные перенос и устаревание;
неизвестная модель; неверные координаты; повреждённое или прерванное обновление.

Принятые границы: отсутствуют обещания непрерывного 3D, мгновенных переносов и
полноты всех запусков мира. Обновляемые изображения остаются обязательным
контрактом; ограничения SDK требуется измерить, а не скрыть жёстко зашитыми
картинками. Поведенческие доказательства и DAG до реализации не сфабрикованы.
