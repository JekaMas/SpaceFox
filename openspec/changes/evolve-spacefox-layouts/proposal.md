# Proposal

## Why

Eight hand-composed layouts keep much of the same text stack and do not explore
the design space systematically. The owner requests reference research, competing
text/geography hypotheses, measured elimination and successive generations.

## What Changes

- Add a reproducible browser design laboratory with at least 200 unique candidates
  across three generations, frozen metrics, lineage, failures and a held-out set.
- Explore metadata rows, pairs, distributed labels and multiple geographic scenes.
- Compare with H/C/E and shortlist one map, globe and horizon using hard constraints,
  Pareto measurements and separately recorded visual judgment.
- Retain the original gallery and native/device qualification boundary; publish
  original research/specs under MIT with existing dependency licenses.

## Capabilities

### New Capabilities

- `layout-research`: repeatable candidate generation, rendered measurements,
  lineage, filtering and bounded finalist qualification for the browser laboratory.

### Modified Capabilities

None in this change. Research findings inform the pending native watchface plan;
the owner's new instruction allows exploring metadata outside a single right-hand
column. Original native time/health/feed/uncertainty obligations remain intact.

## Impact

New `prototype/research/` renderer, metrics, deterministic generator and UI;
`tests/test_layout_research.py`, research reports and retained browser receipts.
Reuse existing local fonts, world topology, examples, D3, TopoJSON and Lucide.
No package install, recurrent agent service, live data fetch or native build.
