# Layout research acceptance record

## Authorized scope and frozen objective

The owner requests broader reference research, competing text/geography hypotheses,
hundreds of measured candidates, elimination, new generations and a finite goal.
The initial 192/48/24 plan and thresholds were recorded before semantic code and
browser measurement. The planned evidence graph validated with eight planned
positive/negative cases before implementation. Native implementation remains open.
Publication authority continues from the existing public SpaceFox source request.

The first three generations supplied 264 parameter-unique candidates. Later
bounded repairs/curation bring the total to 319, not a claim of 319 unrelated
design concepts. The final record contains 1914 current training renders plus
three 24-scene finalist regressions. Additional historic renders are not counted
as unique candidates or fresh independent validation.

## Actual owners and evidence

- `prototype/research/generator.js`: deterministic parameters, uniqueness,
  measured parent selection and explicit mutations. `fixtures.js`: fixed
  training and validation data, reusing canonical coordinates/examples.
- `renderer.js`: real DOM/SVG, canonical geography/artwork, intrinsic text width,
  projected point/land with one projection, and unavailable-coordinate behavior.
- `metrics.js`: constraint detector, sampled geographic viewport, summaries and
  saved-campaign qualification. The heuristic rank never rescues a hard failure.
- `lab.js`: ordinary controls, measured 390×390 offscreen laid-out scenes,
  current catalog audit and visible read-only exports. No external agent loop,
  paid service, simulator, SDK or live launch API is used.
- `tests/test_layout_research.py`: eight exact cases invoke the real JS owners.
  Literal rectangles, a 100-pixel² geographic window, deliberate malformed inputs,
  parent/duplicate failures and incomplete receipts provide independent examples.
  The qualification-positive case also validates the actual saved final campaign.
  Receipt validation is not a new browser rendering or physical-device test.

CUA invoked normal page controls; read-only DOM receipts were saved from visible
JSON exports. No hidden app-state evaluator or alternate browser driver was used.
The rendering bed is outside the viewport but participates in real browser layout,
at 390 logical pixels after local font loading. Its numerical measurements are
not a GPU benchmark, on-wrist legibility result or power estimate.

## Failures and bounded repairs

1. A negative unit example found that a 0.01 font tolerance accepted 18.99 for a
   19-pixel threshold. The detector tolerance was reduced to 0.0001; the unchanged
   expected failure then passed, with its paired valid case.
2. The first browser detector's "healthy" fixture was incorrectly left-aligned
   near the circular corner. Actual bounds proved `circle:time`; centering that
   fixture repaired the harness without relaxing the circle constraint.
3. A common badge style overrode a declared 16-pixel glyph with 13.65 pixels.
   That source defect was corrected, G1 rerendered, and the preliminary G1 export
   preserved. The substantive G1 site-circle/countdown failures remained.
4. G2 packs the footer from the measured longest site width and circle geometry.
   It produced 39/48 current survivors; G3 produced 21/24. Rejected candidates
   remain in their generations.
5. Initial validation rejected all three leaders: 99 999 steps overflowed fixed
   cells; the longer Vulcan title approached the geographic marker. G4 introduces
   content-width fitness cells and whole-projection repositioning. Its uniqueness
   validator rejected duplicate proposals after grammars converged; two duplicates
   were removed and retained in the proposal-rejection record, leaving 22 candidates.
6. Visual review rejected high-area poster/rectangular horizon clipping and
   separate dark stickers behind labels. G5 brought back small round globes,
   moved the horizon camera and dimmed geography; self-review is kept separate
   from numerical ranks. G6's actual cap clearance discriminated curved horizons
   from a straight viewport cut; 70° was chosen with >=12.55 pixels clearance.
7. Visual inspection caught a short ellipsis in Vulcan Centaur despite integer
   scroll/client measurements. At a preview size, the full run plus padding
   exceeded a 119.9766-pixel span by roughly 0.06 pixels, while both integer
   measures were 120. The corrected detector reads DOM Range plus padding/border;
   a 0.25-pixel negative browser probe now fails as intended. G7 tests 16/16.25/
   16.5 title sizes, preserving the 16-pixel metadata floor. The **entire 319-candidate
   catalog** was remeasured; the earlier detector's clean statuses are historical.
8. The stale indicator was restored to an independent cloud-off symbol rather
   than an ambiguous energy-like glyph; all current geometry was then reaudited.
9. Extending the unit generation test initially referenced an undefined test-local
   variable `br`. That harness error was corrected; its affected exact case passed.

The original validation fixtures used the available family schematic for two
