## Candidate ownership changes and current evidence

- `LocalePresentation.suspend()` now drops dictionary/font handles on hide; hidden settings update does not reload them. OFF deliberately retains the resumable owner under the existing policy. The directed three-cycle fake-timer test records callbacks stopped; that is not a physical memory measurement.
- Scene root validation now checks identity/provenance as fields finish and retains the fields needed by rendering and cross-field checks. Role wrappers are checked against packet identities before their compact reference is retained. The root schema's presence bits are set by its existing key validator; sorted/duplicate checks remain in the parser.
- SFR shard tuples share a single compact 32-byte digest with the closure list; full lowercase hex is produced at immutable Storage read/transfer validation/durable pointer boundaries. No extra wire format is introduced. Decoder pixel digest and immutable byte hash are still checked. A captured 19-shard input and refusal tests are bounded examples, not an exhaustive proof of all 4096-byte descriptors.
- At `menu-compact2.log`, equality/duplicate/conflict/order/storage digest and corrupted object controls passed; this precedes the subsequently added pixel-digest control. `compact-remote-observer.log` passed the former parser stall but crashed with OOM after map row 344 during revision 88. It does not establish the precise allocation owner or distinguish VM heap from graphics pool. Phase instrumentation is ongoing; no release-ready claim.
