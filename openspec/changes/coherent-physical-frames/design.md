# Design and investigation

Trace OS display/lifecycle events through the existing lifecycle and rendering/resource owners. A visible paint must select one coherent mode and complete required typography and field identity resources; optional art or unavailable data cannot select a hybrid ACTIVE composition. Hidden and OFF perform no painting. LOW retains the qualified launch point and sparse map, subject to the AMOLED pixel budget. Countdown cues use one presentation rule. Preserve current update and resource limits without extra timers.

Event properties use independently controlled OS mode, visibility, time, settings, provider and resource results, with assertions after every event. Four slots cover actual picker classes and identities; arbitrary external publishers are not finite or exhaustively known. Record exact event disposition and replay, and distinguish fake providers, simulator and physical observations.
