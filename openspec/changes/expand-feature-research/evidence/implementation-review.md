## P1 — actual visual aliases inflate the experiment count

**Observed.** G1 candidates `F1-12-3` (fine-grid) and `F1-12-7` (contour) have all 32 raw observation objects exactly equal to ANCHOR. Equality of observations alone would not prove paint equality, because G1 does not retain every painted style. Here source inspection supplies the missing evidence: the inherited `.geography .grid` CSS fixes stroke-width at .5, while `.geography .land` fixes it at .6; these CSS rules override the new SVG presentation attributes intended to use .35/1.3. The feature stylesheet changes colors but did not override those widths. No other branch changes quiet/fine-grid/contour rendering in these initial configurations. The signature nevertheless treats their settings as distinct.

**Observed source-defined no-op descendants.** The selected G2 parent list includes typography roboto-airy, rocket outline/technical, and decor no-grid/latitude-only/fine-grid. In the reviewed renderer, roboto-airy tracking is the literal .6 regardless of typography tuning; outline/technical widths are fixed before the generic rocket tune branch; no-grid has no active decor tune; latitude/fine-grid widths are CSS-overridden. These are actual inactive parameter changes, not merely visually similar designs. Sources: `prototype/features/renderer.js:30`, `:56`, `:49`, and the inherited qualification stylesheet. Some unselected flat-card/capsule-group separator tunes are likewise not consumed in those branches.

**Required disposition.** Repair the active parameter owners, preserve the original records, and remeasure affected rendering/measurement inputs before downstream selection. Validate the final current corpus using a descriptor of actual paint and layout. Exclude candidate IDs, datasets, settings tags, aria-only values and raw overridden SVG attributes from the distinctness fingerprint. A descriptor containing an ignored parameter is not proof that the parameter changed pixels. A plain JSON setting signature remains an important catalog guard but is not sufficient visual deduplication by itself.

## P1 — fitness text contrast is measured from the icon

**Observed.** In the reviewed feature renderer’s measurement loop, the selector was `face.querySelector([data-role="field0"])` rather than `.label[data-role="field0"]`. Both the icon SVG and value span carry that role, and the icon is first. The feature layer overwrites the correct old text measurement with the SVG’s inherited `color`, although the actual value label has its own inline color.

For ANCHOR the retained field contrast is **17.7361684924**, exactly the contrast of inherited `#edf3f7` over `#050a11`. The actual value label source uses `#d4dfeb`, whose independently calculated ratio is **14.7019338843**. The same selection error appears in all 3,200 G1 records, including legacy controls and palette/role variants. Source: `prototype/features/renderer.js:127` as reviewed.

**Consequence.** This is an evidence/measurement defect; it does not establish that the shown themes physically fail contrast. The declared colors remain above the text threshold. Nevertheless a source-exact contrast receipt cannot be accepted from this corrupted channel. The current ordering function uses failure counts, gap and land area rather than this contrast number, and the declared colors remain above the threshold; I do not infer that this bug alone changed the observed pass count or ranking. The complete independent audit records contrast-source failures rather than reporting 72 fully qualified source-exact candidates.

**Required disposition.** Use an unambiguous value-label selector and actual computed colors, bind the correction, and remeasure or explicitly re-audit the affected channel without overwriting the first snapshot. Check every field-role selector for the same icon/value collision.

## P2 — geographic evidence can contradict the source and still qualify

**Executed negative probes.** On an otherwise healthy retained ANCHOR record, the reviewed current detector accepts all three of the following with an empty failure list and `qualify.passed=true`:

1. Replace `geo.sourcePoint` with a different finite point.
2. Make `landArea` exceed `viewportArea`.
3. Make `viewportArea` negative while keeping landArea zero.

Receipt: `implementation-guard-probes.json`; reproduction: `guard-probes.js`. These findings concern malformed evidence acceptance, not a claim that actual G1 geographic observations were corrupted. The detector must require an exact source-point match, finite nonnegative areas and `0 <= landArea <= viewportArea`, with null point identity and zero information area when coordinates are absent.

The numeric out-of-class guards for an excessive energy value and a negative countdown were already working when these probes ran. Unknown language and invalid latitude still produced no outside-class diagnostic in that observed revision; record diagnostics without silently rejecting accepted product inputs. The source was evolving during review, so the probe receipt binds its exact revision rather than asserting these holes persist after author repairs.

## Slot mapping clarified before screening

The first reviewer schema added a universal physical row-major assumption. That was stronger than the user's actual requirement to preserve configurable field identities and values. The author explicitly clarified, before screening/source freeze, that paired columns intentionally introduce a different reading route. I accept that correction to the reviewer-added assumption.

The fields array identifies logical slot identities. A frozen candidate must declare its logical-slot-to-position mapping, and the independent spatial audit must check observed roles/values/positions against that mapping. DOM order alone is insufficient; neither is a universal row-major assumption. This does not permit omissions, duplication or role/value substitution. The amendment is explicit in `slot-mapping-clarification.md`; both initial seals and original packet files are retained. No sealed scene, ID, label, number, coordinate, flag or oracle slot identity was altered.
