# Frozen protocol, before candidate selection

Question: which new feature combinations produce five coherent, distinct browser proposals while preserving launch and fitness information? Experimental unit is one rendered candidate/scene, not a person. Repeated scenes are deterministic stress cases, not independent human samples. No p-values or claims of glance speed/preference from geometric ranks.

Canonical matrix: docs/FEATURE_MUTATION_MATRIX.md; executable levels will be prototype/features/axes.json. Use eight NON-anchor levels per axis to avoid counting the shared anchor twelve times. ## Type, semantics and geography

Normalize each numeral font on actual Canvas ink for08:08 to58.5px, tolerance±2; require actual scene clock ink≥55. This is an explicit new physical-size proxy, not a retrospective change to round2's80px font-size contract. Other round2 size floors and4px critical gaps remain. Retain both line boxes and ink rectangles; do not count accessibility labels as visible text. Fonts loaded from local, licensed originals. Contrasts use computed colors and declared worst-case background; shapes/text duplicate status color.

Use exact approved localized display labels and retain full source strings. Schema/class bounds come from independent reviewer; fields cover steps/calories0..99999, energy/stress/battery0..100, heart0..240 or unavailable. Class uses four distinct roles; repeated settings remain accepted and explicitly outside the finite benchmark. Countdown is a local interval to a scheduled timestamp, not NASA mission-control T-clock, hold state or proof of liftoff.

Geography tests projected marker position, finite coordinates, visibility and clearance. Measure unobscured geographic viewport separately from visible LAND samples using actual SVG fill geometry. No coordinates means no invented marker and zero geographic information area. Large ocean windows must not win solely by their rectangle. Maps carry no false north arrow. Visual recognizability remains an independent review judgment.
