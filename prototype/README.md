# Макет «Миссия»

[Галерея восьми компоновок и четырёх шрифтов](layouts.html) ·
[оценка эргономики](../docs/DESIGN_RESEARCH.md). Галерея работает со своими
локальными библиотеками/шрифтами и не обращается к API расписания.

- `mission.template.html`, `mission.js`, `i18n.js` — редактируемые исходники.
- `mission.html` — собранный HTML-фрагмент с общим языковым каталогом.
- `index.html` — самостоятельная оригинальная оболочка SpaceFox под MIT.
- `standalone.css` — стили оболочки; `vendor/` — Lucide, D3 и TopoJSON со своими лицензиями.
- `launch-examples.json` — общий источник трёх демонстрационных запусков для
  основной «Миссии» и галереи; координаты/названия не дублируются в layout-коде.
- `layouts.html`, `layouts.js`, `layouts.css` — экспериментальные компоновки.
- `layout-data.js` и `layout-rocket.css` — собранные данные/схемы из общих исходников.
- `fonts/` — локальные WOFF2 и точный манифест источников; лицензии в `../licenses/`.

Откройте `index.html` в браузере. Для загрузки шрифтов и статических библиотек
нужно подключение к интернету. Вызовов API расписания здесь нет.
Для новых вариантов откройте `layouts.html`: её библиотеки и шрифты уже включены
в репозиторий. Кнопка «Рассмотреть» увеличивает каждый вариант; общие настройки
позволяют сравнивать одинаковые данные и шрифты сразу на всех восьми.

Можно выбрать пример запуска, глобус/карту, состояние переноса или устаревших
данных, язык, поля, анимацию и попробовать кнопку «Поднять руку». Поддержаны
36 черновых переводов; настройки сохраняются в браузере. Геометрия v4 сохранена.

После правки исходников или `../locales/*.json` выполните:

```sh
python3 -B tools/build_preview.py
python3 -B tools/build_preview.py --check
```

Команды запускаются из корня репозитория. Вторая обнаруживает устаревший HTML.
Встроенная служебная оболочка прежнего экспорта Codex удалена из текущего файла.
Условия сторонних материалов — в [уведомлениях](../THIRD_PARTY_NOTICES.md),
границы локализации — в [руководстве](../docs/LOCALIZATION.md).

Фитнес-значения и расписание условные, миниатюры схематичные. Часы макета
используют часовой пояс Asia/Dubai; нативная версия обязана брать местное время
с Garmin. Это не Monkey C, не программа `.prg` и не замена проверки на часах.
