# Historical named reference inventory

The saved 11 November 2026 LL2 API 2.3.0 query results are a historical source slice, not proof of present worldwide coverage or operational qualification. Site country is distinct from rocket origin, manufacturer and operator; two sites had unknown country in that snapshot. Numerically valid coordinates do not establish precise site positions. The complete records, coordinates and 350 organizations remain in the [raw reference inventory](../openspec/changes/spacefox-watchface/evidence/global-catalog/reference-inventory.json), with scope and gaps in the [audit](GLOBAL_CATALOG.md). The [current catalog](GLOBAL_VISUAL_CATALOG.md) owns current coverage.

This English condensation is not a new query. The original report and its named tables are available as the [previous public report](https://github.com/JekaMas/SpaceFox/blob/59f16c43b453db0573a43d5ebec98a0b019a08fd/docs/GLOBAL_CATALOG_INVENTORY.md); provider attribution and terms remain applicable.
