# Historical feature mutation matrix

This 390 × 390 browser-study protocol recorded eight nonbaseline options per feature, four descendants of measured parents and a separate anchor. It varied architecture, geographic projection and window, mission layout, fitness representation, typography, palette and color roles, separators, rocket depiction, status placement and decoration. Measurements included complete values and roles, bounds, contrast, marker geometry and map signal. A geometric pass did not establish recognition, preference or reading speed. See [historical progress](../openspec/changes/expand-feature-research/PROGRESS.md) and [research results](FEATURE_RESEARCH.md).

This English condensation is not a rerun or current product menu. The original full parameter matrix, hypotheses and measurement plans are available as the [previous public report](https://github.com/JekaMas/SpaceFox/blob/59f16c43b453db0573a43d5ebec98a0b019a08fd/docs/FEATURE_MUTATION_MATRIX.md).
