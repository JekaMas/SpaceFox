# Public source workflow

This public snapshot uses the OpenSpec changes in `openspec/changes/` and ordinary
Git changes. See README.md for validation/build commands. Task lists remain in
those changes; keep actual evidence and native/device limits explicit.

The author's local JekaMas SDD integration is development tooling, excluded from
this public snapshot. References to its pinned validators in historical evidence
are provenance, not bundled commands or a promise that the tooling is available.
No Garmin SDK is bundled. Do not silently install tools or publish/deploy changes.

The browser prototype uses simulated schedule/fitness values. Translation files
are draft resources, not proof of native firmware support. Source tests can be
run with Python and existing Node, and OpenSpec checks artifact structure only.
