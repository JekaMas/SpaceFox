# Автономное обновление SpaceFox

Компьютер с агентом не входит в рабочую цепочку расписания. Cloudflare запускает
сохранённый Worker по Cron `7,22,37,52 * * * *` (UTC). Worker отправляет один
запрос запуска в GitHub. Код издателя выполняется на GitHub-hosted Ubuntu 24.04,
читает исходники и долговечное состояние из Git, проверяет срок обновления,
получает данные Launch Library 2 и публикует проверенный набор в GitHub Pages.
Часы загружают его через сопряжённый телефон с Garmin Connect.

У агента нет регулярной работы в этой цепочке. Локальный Python, SDK, браузер,
открытый чат, запущенный симулятор и домашний сервер для неё не нужны. Секрет
запуска хранится в Cloudflare как encrypted Production Secret. Внутри Actions
используется выдаваемый GitHub токен задания. Состояние не зависит от диска Mac
или срока хранения временного Actions artifact.

Вызов каждые 15 минут проверяет, наступил ли срок: обычно источник читается раз
в час, ближе к запуску — чаще. Изменение секунд отсчёта вычисляют сами часы.
Изменённые данные/ассеты публикуются полным согласованным набором. Существующие
неизменённые ассеты используются по digest. Полный каталог и получение его
метаданных находятся вне часов; неполная фоновая выборка не выдаётся за готовый
полный каталог и не подменяет активный набор без принятия.

## Что фактически проверено

13 ноября 2026 года выполнена одна проверка всей удалённой цепочки; последующие
штатные обновления не требуют постоянного наблюдения агентом.

- Сохранённые настройки Cloudflare: нужный Cron, encrypted secret, действующая
  версия `670096a0`, совпадающая с ранее прочитанным исходником Worker.
- В Workers Observability за час — четыре успешных события `scheduled`, ноль
  ошибок. Событие в15:22UTC имеет `executionModel=stateless`, `outcome=ok` и
  соответствует запуску GitHub. Это реальные события сервера, не ручной Run.
- Автоматические [циклы13:22](https://github.com/JekaMas/SpaceFox/actions/runs/43433017023)
  и [14:22](https://github.com/JekaMas/SpaceFox/actions/runs/43442034551) завершили
  все пять jobs: prepare, arm, deploy, promote, metadata. Журналы каждого job
  указывают GitHub-hosted Ubuntu runners; локального runner нет.
- Поколения2 и3 получены после реальных запросов к источнику. Его проверка
  продвинулась с1794576343 до1794580012. Одинаковое время запуска осталось
  одинаковым; время проверки источника не подделано изменением версии.
- Публичный HTTPS `/feed.json` вернул поколение3. Полный набор96файлов/616444байт
  проходит текущий валидатор. Повторно использованы95 неизменённых файлов из
  прежнего полного HTTPS-наблюдения; job promote отдельно проверил полный
  актуальный HTTPS-набор. Это не96 новых загрузок агентом.

Отдельно локальный официальный симулятор сам загрузил поколение4: ближайший
запуск сменился с Vulcan/Cape Canaveral на Starship V3/SpaceX/Starbase; поменялся
и digest набора графики. Из пустого кеша активировались карта, ракета, флаг и
знак оператора; принятый JSON точно совпал с публичным HTTPS. Холодное повторное
открытие восстановило тот же JSON/source age/графику/commit seal без HTTP и
фоновых callback. Оба обычных прогона и очистка завершились exit0. Этот G4
создан серверным source-due циклом на событие push предыдущего изменения
документации; он не выдаётся за третий естественный Cron. Два естественных
цикла выше проверены отдельно.

Проверен и переход уже установленного экземпляра: его настоящий сохранённый
кеш поколения1 с Vulcan автоматически заменён данными и графикой поколения4.
Перед обновлением проверены точные прежние hash/age/generation; после — точные
новые hash/модель/место/набор графики. После холодного повторного открытия
обновлённый commit seal сохранился, HTTP и фоновых callback не было. Содержимое
кеша не подставляли и не сбрасывали. [Результат обновления](../openspec/changes/spacefox-watchface/evidence/local-autonomous-delivery-20261113/INPLACE-RESULT.json).

[Локальный результат и настоящий снимок390×390](../openspec/changes/spacefox-watchface/evidence/local-autonomous-delivery-20261113/RESULT.json).
Первая проверка со старым ожидаемым Vulcan остановилась при смене настоящего
расписания; её отказ сохранён. Новая проверка использовала фактический G4 и
исходные точные утверждения о wire hash, запуске, месте и графике.

Точные записи: [autonomous-updates-20261113](../openspec/changes/spacefox-watchface/evidence/autonomous-updates-20261113/).
Программные свойства издателя и таймера прошли отдельную независимую проверку;
её границы и оставшиеся проверки восстановления — в
[PROGRESS](../openspec/changes/spacefox-watchface/PROGRESS.md).

Фактическое выключение Mac не проводилось. Вывод об отсутствии зависимости
от него основан на проверенной конфигурации, исходниках и выполнении всех
звеньев на удалённых серверах. Доставка на физические часы через телефон ещё
не наблюдалась; текущие локальные проверки используют официальный симулятор.
Публикация в Garmin отложена владельцем.

## Условия работы и обслуживание

Для получения новых данных нужны работающие Cloudflare, GitHub и источник;
для доставки на часы — интернет и сопряжённый телефон. Без связи часы сохраняют
последние принятые данные и считают время локально. Пропущенный вызов таймера
повторяется следующим событием; издатель хранит состояние для восстановления.
Завершение POST/dispatch само по себе не считается успешной публикацией.

У созданного ограниченного GitHub-токена записан срок **12 ноября 2027 года**.
До истечения его потребуется заменить в том же encrypted secret. Это не требует
постоянно работающего компьютера. Разрешения остаются только для SpaceFox:
Actions write и Metadata read. Значение токена не входит в исходники или логи.

Cloudflare описывает [серверные Cron Triggers](https://developers.cloudflare.com/workers/configuration/cron-triggers/).
GitHub предупреждает, что [scheduled workflows могут отключаться после60дней
без активности](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/disable-and-enable-workflows).
Основной наблюдённый таймер здесь внешний; фактические обновления сохраняют
новое состояние в репозитории. Это не гарантия доступности внешних сервисов
на неопределённый срок. При сбое достаточно разбирать причину и восстанавливать
цепочку; штатное обновление не требует ручного подтверждения или проверки.

Изменение кода циферблата — отдельная более высокая подписанная версия и путь
через Garmin. Оно не происходит автоматически от обновления JSON. Добавление
или исправление исходного рисунка/места в принятом каталоге запускает серверную
сборку данных; новая версия нативной компоновки для этого не нужна.
