# SpaceFox 0.2.5

This release closes the current runtime audit. Due launch schedules are acquired on the same eligible prepare invocation, while pending recovery, shared quota and in-flight serialization remain in place. Metadata retains its Retry-After guard; a schedule 429 retries at the next permitted connected opportunity. Healthy schedule checks remain hourly; offline wake, freshness and daily metadata cadence remain separate.

The native freshness calculation has one owner, the browser preview reuses date and time formatters, and the unused legacy ISO parser has been retired from production. Map projection and paged world geometry retain their bounded frame-local design; no speed, memory or battery improvement is claimed. The watch consumes the trusted `/watch.json` schedule; `/feed.json` remains the publisher and visual root. Countdown preserves source precision; scheduled T0 is not liftoff confirmation. Reminders remain off by default.

The FR165 and FR165 Music PRGs and portable USB install ZIP are attached, together with the IQ, all supported device programs, source inputs, licenses and original build receipt. Default language is English. Physical installation, notification delivery and haptics, phone transport, battery use and Store acceptance are unobserved. The earlier 0.1.18 physical IQ error remains unexplained. No 0.2.5 Garmin Store submission is claimed.
