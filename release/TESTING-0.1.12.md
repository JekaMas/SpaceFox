# 0.1.12 test boundaries

This is a signed test build. Existing 0.1.11 is its published GitHub test predecessor; 0.1.12 is a published GitHub test prerelease and is not Garmin-approved. After installation, check the version in SpaceFox settings before attributing a result to this build.

The local SDK controls cover an unsupported feed rejection, preservation of the previous accepted data and age, separate feed-host state, actionable Settings guidance, and updating that guidance when the menu language changes. They use controlled inputs and an SDK simulator. The actual 0.1.12 FR165 and FR165 Music programs were also observed displaying an offline simulator screen. Neither observation establishes physical watch, phone, live feed, operating-system recovery, Store update, or migration behavior.
