# SpaceFox installation

The 0.2.3 release package contains signed FR165 and FR165 Music PRGs and a portable install ZIP. Once published, obtain them from the [0.2.3 GitHub release](https://github.com/JekaMas/SpaceFox/releases/tag/v0.2.3). The [0.2.2 release](https://github.com/JekaMas/SpaceFox/releases/tag/v0.2.2) is its predecessor. The original [SpaceFox Connect IQ listing](https://apps.garmin.com/apps/7ef095e4-72fe-44cd-bc39-8987b6ab49e3) was previously observed showing 0.1.18/Internal 11 **PENDING** in owner preview; public approval is not established. A Forerunner 165 Music installation was queued for the next synchronization after all six permissions were accepted. The owner separately installed 0.1.18 on a physical non-Music Forerunner 165 and reported missing point/time followed by an IQ error; its cause is unknown.

Download the PRG matching the watch from the 0.2.3 GitHub release and copy it to `GARMIN/APPS` using a USB data cable. Safely eject, disconnect and select SpaceFox. Check the version in settings. The IQ file is for Store distribution; a phone cannot directly install a PRG or IQ by tapping it. Whether settings or cache survive this update is unverified.

On the physical FR165, check the first frame, acquisition, ACTIVE/LOW/OFF, a reopen and at least 15 minutes of ordinary use. With reminders enabled, observe notification and quiet-mode behavior; scheduled T0 does not confirm liftoff. The 0.1.18 IQ error was reported on this model and its cause is unknown. If a failure occurs, preserve the private `GARMIN/APPS/LOGS/CIQ_LOG.YML` and rotated backup for diagnosis; do not post unredacted device logs publicly.

English and `https://jekamas.github.io/SpaceFox` are defaults. Active mode has four configurable fields and seconds; always-on mode shows the map outline and point, clock, date, minute countdown and battery without those four fields. Accepted data remains available offline, including its validated upcoming queue. The live feed was observed carrying upcoming launch metadata on 15 November 2026. A validated inexact announced NET displays `T−` or `T+`; elapsed time is relative to that announcement, does not confirm liftoff, and does not change reminder eligibility. With no announced reference the countdown is unknown.

The 0.2.3 candidate declares the same six Garmin permissions: SensorHistory for recent heart/stress samples; ComplicationSubscriber for current Body Battery when selected; Communications for the public feed; Background for scheduled refresh; Notifications for enabled launch reminders; and UserProfile for quiet-time settings. Body Battery availability depends on the watch and its permissions. Reminders are off by default.

In watch settings, use **Field 1–4 → More sources** to select available watch sources. In phone settings, **Selected on watch** uses the last source selected on the watch for that field. Future models require separate qualification.

For historical context see the [0.1.18 publication record](https://github.com/JekaMas/SpaceFox/blob/29f3cfd067ff10690a9ba5163f25e04cd4b55b6f/openspec/changes/spacefox-watchface/evidence/fields018/publication/PUBLICATION.md). Physical installation and behavior of 0.2.3, phone delivery, wake time and battery use remain unverified. Do not include credentials or private health data in reports.
