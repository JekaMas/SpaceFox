# SpaceFox 0.1.18

The four active fields can use sources available on the watch: Garmin system and accessible user complications plus supported daily activity readings. Existing choices, colors and slot assignments remain. The watch picker adapts to the device; temporarily unavailable readings show a dash and saved provider identities remain in place. Always-on mode continues to omit the four fields.

In phone settings, **Selected on watch** uses the last source chosen for that position in the watch settings. The phone list is static and does not enumerate each watch's installed providers. The established six phone choices remain available, and returning to **Selected on watch** restores the last saved source.

The package targets the documented device profiles. Simulator and compiler checks do not establish physical watch installation, device behavior, phone synchronization or Garmin Store approval.
