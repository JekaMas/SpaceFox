# SpaceFox 0.1.11 test notes

This signed candidate includes the independently reviewed current native UI and selected-map/redraw repairs. The five primary language modes are English, Russian, German, French and Spanish; Auto is also available. Defaults are English and the SpaceFox public feed. Four fields and six independently configurable colors are available. LOW display refreshes at the device's permitted minute cadence. The remaining 31 locale resources are retained on a best-effort basis.

The current UI observations were made with SDK 9.3 and a simulator using test identities. They predate this version-only build; they are not new physical-device observations or a claim of a fresh higher-version simulator run. The signed candidate's actual SDK exports, profile inputs and signature inspection are recorded in release.json. See INSTALLATION.md for transfer and test steps.
