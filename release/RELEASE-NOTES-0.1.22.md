# SpaceFox 0.1.22

This regular release integrates the 0.1.21 clock-first and incremental feed work with bounded native resource ownership, retained-map/point and countdown behavior, and host-side feed-processing improvements. Four configurable fields, the existing five primary languages, LOW and active displays, and accepted offline launch data remain supported.

A reported IQ error on a physical non-Music Forerunner 165 with 0.1.18 remains unexplained. Exact-candidate installation, everyday use, phone delivery, battery behavior and Garmin Store approval have not been observed. Simulator measurements and software qualification are recorded separately in the performance integration evidence.
