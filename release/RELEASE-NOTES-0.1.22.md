# SpaceFox 0.1.22 — GitHub test prerelease

This update restores coherent launch facts and a source-point fallback while artwork is unavailable. Countdown hours accumulate beyond one day, reach T+ at zero and retain the selected launch for at least 15 minutes or a later sourced ascent end. Passing zero is not confirmation of liftoff.

A `~` marks a source time given to the minute. Dashes mean no usable target is available. A `?` beside a point marks unverified source-reference coordinates; a `?` without a point means the event location is unavailable. Updates retain one selected launch's name, time, site and point together, including recovery after an interrupted replacement.

English and `https://jekamas.github.io/SpaceFox` remain defaults. Four configurable activity fields remain available. The existing clock-first, streaming and resource-lifecycle repairs are retained.

The owner reported an IQ error on a physical non-Music Forerunner 165 with 0.1.18; its cause remains unknown. Physical 0.1.22 cold startup, reopen and at least 15 minutes ordinary use are unverified, as are physical P1–P6 acceptance, phone update migration and Garmin Store approval. This is a GitHub test prerelease, not a Store submission.

During preparation, the retained IQ-first adapter separately ran a post-export SDK verifier over the IQ and 91 programs. This was a custom release inspection, separate from SDK compilation, and was completed before the later decision to omit further release checks. No subsequent signature or hash audit was performed.
